Tokens And TokenizationInput becomes pieces
Zero to beginning

The model does not read words exactly like we do.

Text is broken into tokens. Tokens are chunks of text the model can count, compare, and predict from.

Cortex gives agents a shared place to remember what matters.
More context costs tokens, but blind work costs rework03 / 12
Context WindowWorking table
Not a brain

Context is the desk space, not the memory.

Memory Versus ContextDurable versus visible
The common confusion

Memory only helps when the agent can use it at the right moment.

Context

What the agent can see right now. Powerful, but limited.

Chat history

Useful until it gets long, noisy, or summarized.

Tool output

Fresh evidence from the repo, terminal, browser, or tests.

Cortex

Durable knowledge in git that agents can load just in time.

CompactionWhen chat gets too big
Long sessions need compression

Compaction is a summary, not a full replay.

When a thread gets long, the system may compress it. Good summaries keep intent and state. Bad summaries lose the sharp edges.

Work happens

Decisions, files, tests, and caveats pile up.

Context shrinks

The system keeps a summary and drops detail.

Handoff saves state

A deliberate handoff keeps the next agent oriented.

Cortex turns important session state into files before it evaporates07 / 12
Dumb In The MiddleFailure mode
Why smart agents still stumble

The model can be brilliant at the edges and fuzzy in the middle.

Start

Clear prompt

The first instruction is crisp and recent.

Middle

Crowded context

Old details, tool noise, and half-decisions compete.

Risk

False confidence

The agent fills gaps with plausible guesses.

Fix

External anchors

Files, tests, roadmaps, and skills keep the work grounded.

The answer is not more chat. It is better anchors.08 / 12
Why Cortex ExistsShared memory in git
Small extra context, large gain

Cortex gives agents a map before they start walking.

The team pays a small token cost to load the right skills, then saves time by not reteaching the same project habits every session.

Cost

A few more tokens at the start of work.

Gain

Less rediscovery, fewer repeated mistakes, better handoffs.

The goal is continuity, not ceremony09 / 12
